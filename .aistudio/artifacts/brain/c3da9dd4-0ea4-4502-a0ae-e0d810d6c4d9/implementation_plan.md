# 设备设置页新增解绑入口与二次确认跳转方案

在设备信息与设置页新增「解除设备绑定」入口，点击后弹出二次确认弹窗；确认解绑后自动解除当前设备连接并跳转回首页视频回放页面（无设备历史回看模式）。

### User Review & Critical Decisions

> [!IMPORTANT]
> 请确认以下交互细节是否符合预期，点击 **Proceed** 即可立即执行修改：

- **解绑入口位置**：在设备设置页底部（「使用教程与指南」下方）提供醒目的红色警示风格「解除设备绑定」操作入口，同时在顶部设备信息卡片右上角提供快捷「解绑」胶囊入口，方便用户在页面顶部或底部随时操作。
- **二次确认弹窗**：采用移动端居中的高对比度确认弹窗（严格限制在手机视口宽度内），展示当前待解绑的设备名称与型号，说明“解绑后将断开实时画面与新片段录制，云端历史视频仍可继续回放”，提供「取消」与「确认解绑」双按钮。
- **解绑后跳转目标**：确认解绑后，自动将当前设备状态切换为「未绑定设备（含历史记录）」，并立即跳转回「首页视频回放」视图（顶栏显示“未绑定设备”及“+ 绑定设备”按钮，页面保留历史视频回放能力）。

---

### 1. Overview & Core Concept

- **功能目标**：支持用户在已绑定设备的设置页中安全解除当前穿戴设备的绑定关系，并在操作完成后平滑返回首页视频回放界面。
- **适用场景**：督察官或巡检人员在班次结束、更换穿戴终端或归还设备时，需要将当前账号与硬件工牌解绑。
- **核心价值**：通过二次确认防止误触导致的采集中断，同时在解绑后无缝衔接至云端历史视频回放页面，保证历史数据的连续可查阅性。

---

### 2. User Experience & Visual Design

- **核心交互流程**：
  1. 用户在设备设置页浏览设备状态或滑至页面底部，点击「解除设备绑定」按钮。
  2. 页面弹出二次确认模态框，高亮显示当前设备名称（如 `主厨视角设备 · Smart-Glass Pro`）及解绑影响说明。
  3. 用户点击「取消」则关闭弹窗留在当前设置页；点击「确认解绑」则执行解绑并立即跳转至首页视频回放页。
  4. 跳转至首页视频回放页后，顶部导航栏更新为 `督察官: 未绑定设备` 与 `+ 绑定设备` 按钮，播放器与历史切片列表保持可回看状态。
- **视觉与动效设计**：
  - *入口样式*：底部采用 `bg-white` 搭配 `border-rose-200` 与 `text-rose-600` 的警示操作卡片/按钮，兼顾清晰度与视觉克制；顶部设备卡片提供紧凑型解绑标签。
  - *二次确认弹窗*：采用 `backdrop-blur` 半透明遮罩与平滑缩放过渡动效，顶部搭配红色警示图标，主确认按钮使用 `bg-rose-600 hover:bg-rose-700 text-white` 强化危险操作感知。

---

### 3. Key Product Decisions & Trade-Offs

- **决策 1：解绑后跳转至「含历史记录」的首页视频回放模式**
  - *选定方案*：解绑后清空当前激活设备并将状态设为云端历史录像模式，直接展示首页视频回放界面。
  - *原因*：用户明确要求“解绑完成后跳转到首页视频回放”，保留云端历史视频播放器与切片列表能直接满足回放诉求，避免落入无播放器的空白向导页。
- **决策 2：应用内定制二次确认弹窗**
  - *选定方案*：使用内嵌于手机视口容器内的定制模态弹窗，而非浏览器原生弹窗。
  - *原因*：保证移动端视觉风格统一，并且能够清晰展示当前解绑设备的名称与解绑后的状态说明。

### 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **架构与状态流转图**：

```
┌──────────────────────────────────────────────────────────┐
│                     主应用状态容器                        │
│  selectedDevice: Device | null                           │
│  unboundHistoryMode: 'with_history' | 'pure_empty'       │
│  currentView: 'dashboard' | 'settings' | ...             │
└───────────────┬──────────────────────────▲───────────────┘
                │ 传入 device 与           │ 触发 onUnbindDevice()
                │ onUnbindDevice 回调      │ 1. selectedDevice = null
                ▼                          │ 2. unboundHistoryMode = 'with_history'
┌──────────────────────────────────────────┴───────────────┐
│                      设备设置视图                         │
│  ┌────────────────────────────────────────────────────┐  │
│  │ 解除设备绑定入口（顶部设备卡片快捷按钮 + 底部通栏）  │  │
│  └─────────────────────────┬──────────────────────────┘  │
│                            │ 点击打开弹窗                 │
│                            ▼                             │
│  ┌────────────────────────────────────────────────────┐  │
│  │               解绑设备二次确认弹窗                  │  │
│  │      [ 取消 ]                  [ 确认解绑 ] ───────┼──┘
│  └────────────────────────────────────────────────────┘
└──────────────────────────────────────────────────────────┘
```

- **交互状态映射**：
  - `isUnbindModalOpen`：控制设备设置页内二次确认弹窗的显隐状态。
  - `onUnbindDevice`：由顶层状态容器注入设置视图，确认解绑时重置 `selectedDevice = null`、`unboundHistoryMode = 'with_history'`，并将 `currentView` 切换为 `'dashboard'`（首页视频回放）。
