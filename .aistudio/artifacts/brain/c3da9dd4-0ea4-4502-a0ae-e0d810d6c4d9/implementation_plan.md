# 视频片段 SOP 分析次数提示轻量化与文案简化方案

将视频播放器下方的执行状态提醒栏从原有的冗长前缀加厚重蓝底胶囊（`当前视频片段执行状态：[已执行 1 次 SOP]`）简化为干净的纯文字提示 **「已执行 1 次 SOP 分析」**（未执行时显示 **「暂未执行 SOP 分析」**），去掉蓝底色块并将次数数字高亮为蓝色，右侧保留「查看 >」跳转入口。

## User Review & Critical Decisions

> [!IMPORTANT]
> 以下设计决策已根据您的确认选项锁定：

- **确认决策 1（简化文案表达）**：去除冗长的「当前视频片段执行状态：」前缀，已执行状态直接展示为 **「已执行 N 次 SOP 分析」**，未执行状态展示为 **「暂未执行 SOP 分析」**。
- **确认决策 2（轻量化视觉样式）**：彻底去掉原有的高饱和度深蓝胶囊底框（`bg-blue-600 text-white`），改为轻量化纯文字（`text-slate-500`）展示，仅将中间的执行次数 `N` 以蓝色粗体数字（`text-blue-600 font-bold font-mono`）高亮。

## 1. Overview & Core Concept

- **功能定位**：在「当前执行SOP」信息栏下方，以极轻量的辅助文本形式告知用户当前视频片段累计完成的 SOP 分析次数，并提供一键查看分析详情的入口。
- **核心价值**：消除底部蓝底胶囊与上方「重新分析」主按钮之间的视觉冲突（避免同一卡片出现两个高饱和度蓝底色块），让主次层级更加分明、界面更加清爽。

## 2. User Experience & Visual Design

- **视觉规范与样式细节**：
  - *整体布局*：单行两端对齐（`flex items-center justify-between px-1 py-0.5 text-xs select-none`）。
  - *左侧已执行文案*：`已执行 <span className="font-mono font-bold text-blue-600 mx-0.5">{currentExecutionCount}</span> 次 SOP 分析`（整体采用 `text-slate-500` 柔和灰字，仅数字为蓝色高亮）。
  - *左侧未执行文案*：`暂未执行 SOP 分析`（采用 `text-slate-400` 轻量灰字，无胶囊背景）。
  - *右侧操作入口*：保持 `查看 >` 轻量文字链接样式，点击跳转至该视频片段的 SOP 分析结果页。

## 3. Key Product Decisions & Trade-Offs

- **决策：遵循 Zero-Pill 规范，去除静态状态的实心胶囊背景**
  - *实施方案*：将原本包裹在 `bg-blue-600 text-white` 胶囊中的状态文字改为无背景纯文本，仅对数字做语义色高亮。
  - *原因*：实心深蓝胶囊在视觉上极易被误认为主操作按钮，且与上方的「✨ 重新分析」主按钮形成视觉竞争；改为纯文字加数字高亮后，既保留了关键信息的可读性，又大幅降低了界面视觉负担。

## 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **组件结构对比示意图**：
```
改造前：
┌──────────────────────────────────────────────────────────┐
│  当前视频片段执行状态： [ 已执行 1 次 SOP ]       查看 › │  <-- 前缀冗长 + 蓝底色块过重
└──────────────────────────────────────────────────────────┘

改造后：
┌──────────────────────────────────────────────────────────┐
│  已执行 1 次 SOP 分析                             查看 › │  <-- 简短纯文本 + 数字蓝色高亮
└──────────────────────────────────────────────────────────┘
```
- **状态与事件映射**：
  - 当 `currentExecutionCount > 0` 时，渲染纯文本 `已执行 {currentExecutionCount} 次 SOP 分析`（数字 `currentExecutionCount` 使用 `text-blue-600 font-bold font-mono`）。
  - 当 `currentExecutionCount === 0` 时，渲染纯文本 `暂未执行 SOP 分析`（`text-slate-400`）。
  - 点击右侧 `查看 >` 按钮保持原有跳转逻辑（触发 `onNavigateToPlaybackClip` 或 `onNavigateToPlayback`）。
