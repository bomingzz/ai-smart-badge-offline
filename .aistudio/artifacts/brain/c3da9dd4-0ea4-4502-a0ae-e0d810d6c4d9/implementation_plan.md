# 方案 A：底部悬浮「当前执行SOP + 录制新片段」一体式控制条

将原本位于顶部历史视频播放器卡片内的「当前执行SOP」移出，与右下角的「录制新片段」按钮合并为**底部一体式悬浮控制条**，从空间结构上彻底消除“当前执行SOP属于正在回看的历史视频”的误解，让用户一眼明确：**左侧选定的「当前执行SOP」即为右侧「录制新片段」所使用的 SOP 规程**。

## 用户确认与关键决策

> [!IMPORTANT]
> 本方案严格按照您选定的 **方案 A** 执行，同时打通底部切换 SOP 与录制新片段的真实业务联动：

- **确认决策 1（上方历史视频卡片净化）**：从顶部历史视频播放器卡片中移除「当前执行SOP」横条，卡片内仅保留播放器、操作按钮行（含 `重新分析`）及 `已执行 X 次 SOP 分析  查看 >`，专注服务于历史视频回看。
- **确认决策 2（底部一体式悬浮控制条）**：在移动端页面底部（限制在 `max-w-md` 容器内）采用一体式双区悬浮舱设计——左侧展示并可点击切换 `当前执行SOP`，右侧紧邻 `● 录制新片段` 按钮。
- **确认决策 3（录制 SOP 真实联动闭环）**：点击右侧「录制新片段」开启实时录制及保存新片段时，全程使用左侧选定的「当前执行SOP」进行实时核验与自动归档分析。

---

## 1. 概述与核心目标

- **解决痛点**：消除历史视频回看区域与新片段录制配置之间的视觉混淆，让“选定当前执行 SOP -> 录制新片段”成为紧密相连的顺畅操作。
- **核心价值**：
  1. **历史回看区更纯粹**：看旧视频时不再出现令人费解的“当前执行SOP”横条，需要用其他规程重跑旧视频时直接点 `重新分析`。
  2. **新录制因果关系一目了然**：「当前执行SOP」与「录制新片段」左右并排在同一个底部悬浮舱内，点击左侧可随时切换工牌待执行的 SOP，点击右侧即按该 SOP 唤醒工牌拍摄。

## 2. 用户体验与视觉设计

### 布局结构示意

```
┌──────────────────────────────────────────────────────────┐
│  [ 历史视频播放器视口 ]                                   │
│                                                          │
│  [ < 今日 ▽ > ]   [ ⚡ 1X 倍速 ]   [ ✨ 重新分析 ] [↓] [≡] │
│  已执行 1 次 SOP 分析                             查看 >  │
└──────────────────────────────────────────────────────────┘

  14:00                                        5 个录制片段
  ┌─────────────────────────┐  ┌─────────────────────────┐
  │ 14:20 20 0'34"          │  │ 14:20 20 0'07"          │
  │ 主厨装配作业SOP异常核验段│  │ 备料区静默备餐与厨具整备│
  └─────────────────────────┘  └─────────────────────────┘

  ╭──────────────────────────────────────────────────────╮
  │ 📋 当前执行SOP                  │  ┌──────────────┐  │
  │ 🍳 餐饮后厨冷链生鲜与切配... ⇄  │  │ ● 录制新片段 │  │
  ╰──────────────────────────────────────────────────────╯
                (底部一体式悬浮控制条)
```

### 交互细节
- **待机态（底部一体式悬浮条）**：
  - **左半区（当前执行SOP切换）**：顶部小字标签 `当前执行SOP` + 底部图标与规程名（如 `🍳 餐饮后厨冷链生鲜...`）+ 右侧 `⇄` 切换图标。点击后弹出 SOP 选择弹窗，确认后即更新当前待录制执行的 SOP。
  - **右半区（录制新片段按钮）**：醒目蓝底白字按钮 `● 录制新片段`，点击后按左侧选定的 SOP 开启工牌实时录制。
- **录制中状态**：
  - 底部悬浮条平滑切换为录制态：左侧显示 `REC 0:XX · 正在执行：{当前SOP简称}`，右侧显示红色 `■ 结束录制` 按钮。
- **弹窗职责区分**：
  - 从**底部悬浮条左侧**打开 SOP 弹窗时：标题为 `切换工牌当前执行 SOP`，确认按钮为 `确认设为当前执行 SOP`（仅更新录制所用的 SOP，不对历史视频重跑分析）。
  - 从**上方视频卡片「重新分析」按钮**打开 SOP 弹窗时：标题为 `选择 SOP 规程重新分析本片段`，确认按钮为 `确认选择并分析`。

## 3. 技术架构与状态设计

```
┌─────────────────────────────────────────────────────────────┐
│                      Dashboard 组件状态                      │
│  - recordingSopId: SopTaskId (工牌当前执行SOP，供新录制使用) │
│  - sopModalMode: 'recording' | 'reanalyze' (区分弹窗触发源)  │
└───────────────┬─────────────────────────────┬───────────────┘
                │                             │
                ▼                             ▼
┌───────────────────────────────┐ ┌───────────────────────────┐
│  顶部历史视频回放卡片          │ │ 底部一体式悬浮录制控制条   │
│  - 播放器 + 倍速 + 下载 + 视图 │ │ - 左：当前执行SOP (可切换) │
│  - [重新分析] -> 触发reanalyze │ │ - 右：[录制新片段]         │
│  - 已执行 X 次 SOP 分析 查看 > │ │ - 联动 LiveRecordingOverlay│
└───────────────────────────────┘ └───────────────────────────┘
```

- **状态隔离与同步**：
  - `recordingSopId` 默认随当前所选工牌设备自动匹配（例如主厨设备默认 `ck` 餐饮后厨 SOP，配电房设备默认 `ee` 高压电工 SOP），支持用户在底部悬浮条自由切换。
  - 当用户点击 `录制新片段` 时，将 `recordingSopTemplate` 传入实时录制全屏页 `LiveRecordingOverlay` 并在录制结束后按该模板生成新片段与 SOP 质检记录。
