# SOP 步骤时间轴竖线与圆形节点严格居中对齐

在「SOP监督」的步骤核验详情页中，左侧蓝色时间轴竖线此前使用容器 `border-l-2` 配合响应式负边距（`-ml-[31px] md:-ml-[39px]`）定位，导致在桌面端预览手机容器时竖线偏左、未能穿过绿色/红色圆形节点的正中心。本次调整将时间轴竖线与圆形节点改为共享同一水平中心坐标（`13px`），确保在任何屏幕宽度下竖线都严格居中穿过圆形节点。

## 用户确认与关键决策

> [!IMPORTANT]
> 本次调整仅修正左侧时间轴竖线与圆形节点的水平居中对齐关系，保持步骤内容与交互不变：

- **确认决策（时间轴竖线居中）**：移除易受屏幕断点影响的响应式负边距偏移，改为基于圆形节点宽度（`26px`）的精确中心轴线定位（`left-[13px] -translate-x-1/2`），使蓝色竖线精准穿过每个圆形节点的正中央。

---

## 1. 概述与核心目标

- **问题原因**：原实现中时间轴容器使用 `pl-5 md:pl-7` 与 `border-l-2`，而圆形节点行使用 `-ml-[31px] md:-ml-[39px]`，两者在 `md` 断点下的偏移量存在 `3px` 偏差，导致竖线偏离圆心。
- **修复效果**：圆心与竖线共享同一几何中心（`x = 13px`），竖线笔直穿过每个圆形步骤节点的正中心。

## 3. 技术实现方案

- **统一几何中心坐标**：
  - 时间轴外层容器设为 `relative pl-2 pr-0.5 py-2 flex flex-col gap-5`。
  - 使用独立绝对定位轴线元素 `<div className="absolute left-[21px] top-3 bottom-3 w-[2px] -translate-x-1/2 bg-blue-400 pointer-events-none" />`（`pl-2` 即 `8px` + 圆半径 `13px` = `21px`）。
  - 圆形节点尺寸固定为 `w-[26px] h-[26px]`（半径 `13px`），起始位置为容器内 `8px` 处，其圆心恰好位于 `8px + 13px = 21px`，与竖线中心完全重合。
  - 步骤详情卡片设置左边距 `ml-[34px]`，与上方步骤标题胶囊左边缘对齐。
